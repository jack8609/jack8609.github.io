## Chrome 擴充功能：半自動填表（v1）

`extension/` 資料夾是一個 Chrome MV3 擴充功能，把在本網站編輯好的違規資料（車牌、違規項目、日期時間、地點、剪輯截圖/影片）半自動轉貼到政府檢舉網站的表單。

### 安裝

1. 下載本 repo（或 `git clone`）。
2. 瀏覽器網址列輸入 `chrome://extensions`，右上角開啟「開發人員模式」。
3. 點「載入未封裝項目」，選擇 repo 裡的 `extension/` 資料夾。

### 使用方式

1. 開一個分頁到本網站，編輯好違規資料、剪輯截圖/影片，**保持這個分頁開著**。
2. 另開新分頁到目標政府檢舉網站的填表頁面。
3. **第一次使用該網站**：右鍵點擴充功能圖示 →「註冊 / 編輯這個網站的欄位對應」，同意授權後依畫面提示逐一綁定欄位。
4. **已建檔的網站**：左鍵點擴充功能圖示開啟管理彈出視窗，點「立即抓取並填表」，即可把來源分頁的資料自動填入目前頁面；風險欄位（如違規項目、地址細節）會標記「待確認」，請手動確認或修正。
5. 若該網站有綁定附件欄位，填表完成後會跳出「選擇附件並上傳」按鈕，選取檔案即可自動上傳。

### 目前已註冊並驗證過的目標網站（profiles）

| 縣市 | 網站 | 狀態 |
| --- | --- | --- |
| 台北市 | 交通違規檢舉（`prsweb.tcpd.gov.tw`） | 已驗證：欄位對應、自動填表、附件上傳 |
| 新北市 | 違規檢舉（`tvrs.ntpd.gov.tw`） | 已驗證：欄位對應、自動填表、附件上傳 |

欄位對應表（selector）平常存在瀏覽器本機 `chrome.storage.local`；上面兩個已驗證網站的對應表額外匯出成 [extension/profiles/violation-helper-profiles-260820.json](extension/profiles/violation-helper-profiles-260820.json)，可直接使用，不用重新走一次對應模式：

1. 開啟擴充功能管理彈出視窗，展開「更多設定」。
2. 「匯出/匯入設定」區塊點「匯入 JSON」，選擇上述檔案。
3. 匯入後即可直接在台北市／新北市網站使用「立即抓取並填表」。

其他縣市網站沒有現成 profile，需自行走一次「註冊」流程綁定。
